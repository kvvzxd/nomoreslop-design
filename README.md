# nomoreslop

Набор навыков для сайтов и интерфейсов: предметный бриф, содержание, композиция, готовые решения, типографика, цвет и выбранное 3D. Обновление от 27 октября 2026; процесс design — редакция 21.

| Навык | Назначение |
| --- | --- |
| [nomoreslop](skills/nomoreslop/SKILL.md) | Общий бриф и согласование нужных специализаций |
| [nomoreslop-design](skills/nomoreslop-design/SKILL.md) | Композиция, ресурсы, взаимодействие и проверка результата |
| [nomoreslop-typography](skills/nomoreslop-typography/SKILL.md) | Читаемость, иерархия, интервалы, идентичность и шрифтовый ресерч; заменяет прежнее имя nomoreslop-fonts |
| [nomoreslop-color](skills/nomoreslop-color/SKILL.md) | Цветовые роли, палитры, градиенты и согласованные light/dark |
| [nomoreslop-writing](skills/nomoreslop-writing/SKILL.md) | Содержание и тексты интерфейса |
| [nomoreslop-3d](skills/nomoreslop-3d/SKILL.md) | Предмет, детализация, материалы, движение и доставка сцены |

## Получение и установка

Обновление опубликовано в отдельной ветке форка:

```sh
git clone --branch update-nomoreslop-color-typography https://github.com/kvvzxd/nomoreslop-design.git
```

Скопируйте нужные каталоги из `skills/` в каталог навыков своего агента целиком, сохранив `SKILL.md`, справочники и инструменты рядом. Для общего процесса установите оркестратор и необходимые специализации; отдельные color, typography, writing и 3d работают самостоятельно. При замене nomoreslop-fonts архивируйте старую папку вне каталога обнаружения, чтобы не получить две активные версии.

## Использование

```text
Используй $nomoreslop для создания сайта по этим материалам.
Используй $nomoreslop-color для подбора цветовой системы.
Используй $nomoreslop-typography для исправления читаемости и интервалов.
```

Для новой палитры color исследует подходящие разделы Colorsinspo — палитры, градиенты, отдельные цвета и тематические/детальные страницы — и доступные материалы Refero. Каждый новый предложенный вариант получает согласованные светлую и тёмную темы. Исследования психологии применяются с контекстом, без универсальных обещаний эффекта отдельных цветов.

Внешние референсы собираются программно, без computer use/headless/browser automation. Refero MCP требует отдельного авторизованного доступа; установка навыка сама не подключает платный сервис. Доступные каналы, происхождение и ограничения описаны в справочниках соответствующей специализации.

## Проверка

Инструменты используют Python 3.10+. Для некоторых проверок бинарных шрифтов опционально нужны fontTools и, для WOFF2, brotli; зависимости не устанавливаются автоматически.

```sh
python skills/nomoreslop-design/scripts/library.py check
python -m unittest discover -s skills/nomoreslop-design/tests -q
python -m unittest discover -s skills/nomoreslop-typography/tests -q
python -m unittest discover -s skills/nomoreslop-color/tests -q
```

Вызов `library.py start --stage composition` показывает редакцию и путь загруженного design. Unit tests и проверка файлов не заменяют визуальную проверку интерфейса и не подтверждают соответствие всего продукта WCAG.
